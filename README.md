# Module 5: Redis & Key-Value Stores (AI/ML Use Cases)

Демонстрация применения Redis в AI-сервисах: кэширование инференса и ограничение частоты запросов (Rate Limiting).

## Что сделано
1. **Кэширование:** Результаты "тяжелой" ML-модели (симуляция 2 сек) сохраняются в Redis с TTL 60 секунд. Повторные запросы с тем же текстом возвращаются мгновенно.
2. **Rate Limiting:** Использование атомарной операции `INCR` и `EXPIRE` для ограничения запросов к API (не более 3 запросов за 10 секунд на одного пользователя).

## Запуск
1. Запустить Redis: `sudo service redis-server start`
2. Запустить скрипт: `python redis_demo.py`
